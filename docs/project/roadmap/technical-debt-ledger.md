# Technical Debt Ledger

Seeded on 2026-09-12 at Ariad adoption, from the survey that accompanied the
timeout-fence work. Every line names the debt instead of letting it become drift.

| TD-001 | PR #11 (timeout port) | `mcp-{admin,charge,data,edi,financial,mailbox,payment,transfer}/src/api/client.ts` | Duplication | Eight near-identical copies of `KobanaApiClient`. | TD-010 | CV1.DS1 | `mcp-site` dependencies | Build integrity | **`mcp-site` cannot be built from a clean checkout.** It declares `env-paths` and `adm-zip`, but being outside `workspaces` (TD-006) means root `npm install` never installs them, so `tsc` fails on `cache-manager.ts` — and its `prepublishOnly` *is* `npm run build`. | TD-011 | CV1.DS1 | `mcp-site/package.json` `files` | Release quality | `files` is `["dist/**/*", "CHANGELOG.md"]` — the package has a `README.md` but does not ship it, so its npm page renders empty. | TD-013 | CV1.DS1 (merge of PR #12) | `mcp-help`, `mcp-mailbox`, `mcp-site` | Build hygiene | These three packages **track their built `dist/` in git**; the other seven ignore it. 168 artifact files were already committed before Ariad adoption, so it is pre-existing, not introduced — but it means every build inflates a diff with compiled output, and a tracked `dist/` can silently go stale relative to `src/`. The three are exactly the ones whose `.gitignore` lacks a `dist/` line | Reviewing a change to these packages means reading compiled noise, and a stale committed artifact can disagree with the source that produced it | Add `dist/` to the three `.gitignore` files and `git rm -r --cached` the artifacts, matching the other seven. Deliberately not folded into the release story — it is a 180-file deletion that deserves its own reviewable commit | Noted 2026-09-12 | Open |
| TD-012 | CV1.DS1 | `mcp-help/src/api/client.ts` | Drift | The scraper sends `User-Agent: Mozilla/5.0 (compatible; KobanaMCPHelp/1.0)` — a hardcoded `/1.0` that CV1.DS1 deliberately did **not** unify with the package version.
